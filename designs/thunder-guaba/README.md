# 雷霆瓜巴图标

- `generated-source.png`：由 imagegen 生成的透明背景像素风源图，以现有瓜巴切片作为形状参考；电蓝瓜瓤、金黄闪电纹、深青色瓜皮。
- `thunder_guaba.png`：供 Minecraft 1.20.1 使用的原生 16×16 RGBA 图标，从源图以最近邻采样导出，不替换普通瓜巴图标。
- 发行纹理位于目标资源的 `assets/pinkkicore/textures/item/thunder_guaba.png`，Wiki 复用同一 PNG。
- 获取示意图由 `python3 scripts/generate-thunder-guaba-diagram.py` 从实际发行图标生成，修改图标后重新运行该脚本。

耐火是用户确认的材料属性；雷击批量转换与图标均已接入游戏，实际验证范围见 `docs/changes/2026-10-26-thunder-guaba.md`。本次不定义匠魂、寂静装备或 Tetra 材料参数与特性。
