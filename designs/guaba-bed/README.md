# 瓜巴床与梦系道具

瓜巴床占 1×2 格，地面到枕头顶为 9/16 格。被面沿床身绘制土黄色条纹，床头放米白枕头，深棕床框连接四只床脚。两半共用 64×64 贴图。

云梦用拉长的轮廓与向后散开的雾尾，冥梦用紧凑卷曲的轮廓。瓜巴版分别沿用各自的轮廓，用明暗不同的土黄色区分。五张物品图标都是 16×16 像素，Wiki 与游戏共用图标。

- [模型审阅页](review.html)支持拖动旋转、滚轮缩放和五个视角。
- [Blockbench 工程](guaba_bed.bbmodel)内嵌贴图，可直接在编辑器中打开。
- 修改生成源后，在安装 Pillow 的 Python 环境中运行 `python3 designs/guaba-bed/generate.py`。再运行 `python3 designs/guaba-bed/validate.py` 核对工程、预览、游戏导出和 Wiki 图标。

Wiki 配方中的原版白床图标来自 Minecraft Wiki，属于原版素材。 [白床图标](https://minecraft.wiki/images/Invicon_White_Bed.png)
