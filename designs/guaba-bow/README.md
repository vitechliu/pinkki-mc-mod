# 瓜巴弓图标

`pixels.json` 是待机、拉弓 0/1/2 四幅 16×16 字符矩阵；`generate.py` 定义瓜巴红瓤、籽点与土黄瓜皮配色，并同步生成运行时 PNG、Wiki 图标及四帧放大审阅图 `preview.png`。

生成：`python3 designs/guaba-bow/generate.py`（需要 Pillow）。不需要 Minecraft 客户端启动。

原版弓的轮廓、拉弓姿势与箭矢像素参考 Minecraft 1.20.1 本地客户端资源；原版素材属于 Mojang/Microsoft，仓库 MIT 许可证不改变其权属。Wiki 的原版弓图标也来自该资源。
