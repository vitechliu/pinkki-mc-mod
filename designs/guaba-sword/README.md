# 瓜巴剑像素图标

16×16 透明像素图标，保持 Minecraft 1.20.1 钻石剑的对角轮廓，以瓜巴的红色瓜瓤、深色籽点和土黄色瓜皮重绘配色。`generate.py` 的字符矩阵与调色板是可编辑源，生成运行时和 Wiki 的相同 PNG；`preview.png` 为最近邻放大审阅图。

运行：`python3 designs/guaba-sword/generate.py`（需要 Pillow）。

轮廓参考 Minecraft 原版钻石剑，原版素材权利属于 Mojang/Microsoft；Wiki 的原版钻石剑输入图标来自本地 1.20.1 客户端资源，不因仓库 MIT 许可证改变权属。
