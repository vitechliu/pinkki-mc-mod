# 瓜巴龙 · 初版设计

仅设计稿，尚未注册实体、进入发行资源或部署。以用户提供的插画为参考，转译为 Minecraft 长方体和原创像素贴图：无翅双足、短前爪、红色头部底层与蓝色肌肉纹路交替、红色躯干、金色颈腹、火焰状背鬃和分节长尾。背鬃是实体装饰，并非发光材质或火焰粒子。此次以地面站姿呈现，未复制插画的腾空盘曲姿态。

## 比例和关节

16 单位 = 1 格，原点为两脚之间的地面，Y 向上，正面朝 -Z。静态高约 3 格、头尾长约 5 格、躯干宽约 0.9 格；这是视觉尺寸，不是未来碰撞箱。

101 个长方体、24 根骨骼、512×512 RGBA 像素贴图，独立 per-face UV。每面按自身 UV 绘制，未使用插画平面投影。

- `body → neck_base → neck_tip → head → jaw`：颈根、颈尖、头和下颌独立，便于蓄力、瞄准和开口。
- `head → breath_socket`：空挂点位于口部 `[0,31,-30]`，用于后续从头部骨骼取得喷射位置与方向；不随下颌运动，不自带火焰。
- `body → tail_1 → tail_2 → tail_3 → tail_4 → tail_flame`：逐节摆尾，尾尖火焰为几何装饰。
- 前肢分上臂/手，后肢分大腿/胫/脚，预留后续动作；当前没有行走动画。
- `crest`、`neck_crest` 为装饰骨骼，不是乘客或独立生物。

## 动作规格

| 名称 | 时长 | 姿态与未来触发建议 |
| --- | --- | --- |
| `idle` | 3 秒循环 | 小幅呼吸、抬颈、逐节摆尾；未来静止时播放 |
| `breath_pose` | 2.8 秒单次 | 0–0.65 秒抬颈蓄力；0.65–1 秒向前压颈并开颌；1–2 秒张口保持；2–2.8 秒复位。未来喷火攻击状态触发 |

喷火仅提供姿态草案。尚无火焰网格、粒子、发光、音效或攻击判定。后续可在 1–2 秒期间从 `breath_socket` 发射；伤害、射程、冷却、实体物理、AI 和网络同步应独立实现。动画没有实体世界根位移，审阅器没有附加腾空轨迹。

## 文件与复现

- `guaba_dragon.bbmodel`：Blockbench 4.10 GeckoLib 工程，内嵌贴图和两段动作，不含本机绝对纹理路径。
- `guaba_dragon.geo.json` / `guaba_dragon.animation.json`：GeckoLib 基础几何与数值关键帧。
- `textures/guaba_dragon.png`：原创像素贴图。
- `review.html`：内嵌实际导出数据的离线 WebGL 审阅器，无 CDN。支持拖动旋转、滚轮缩放、四种视角、动作选择、播放/暂停、时间轴、骨骼与背鬃开关。
- `generate.py` / `review-template.html`：确定性源文件，建模与审阅渲染基础沿用并适配 `designs/bingwa/`，不会修改饼蛙资产。
- `validate.py`：检查源工程坐标与 UV 往返、PNG 数据与 CRC、骨骼层级、关键帧和审阅数据一致性。
- `check-geckolib.py` / `GeckoAssetCheck.java`：使用本地缓存的项目最低 GeckoLib 4.2.3 和 Forge 1.20.1 解析；不启动游戏。依赖项目已有 `.local` Java 与构建缓存，缺少时明确报错。

从仓库根目录执行：

```bash
python3 designs/guaba-dragon/generate.py
python3 designs/guaba-dragon/validate.py
python3 designs/guaba-dragon/check-geckolib.py
```
