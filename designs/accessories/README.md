# 饰品图标

使用内置 imagegen 生成透明背景源图，按最近邻缩小为发行用 32×32 PNG；源图保留于本目录。发行贴图位于 `versions/1.20.1/src/main/resources/assets/pinkkicore/textures/item/`，Wiki 复用相同 PNG。

- `guaba_hood-source.png`：Minecraft inventory sprite, melon-green and muddy-brown hood, pink metallic rim, empty dark face opening, no person, crisp pixel art, transparent background, no text.
- `pink_blessing-source.png`：Minecraft inventory sprite, four faceted pink ingots arranged as a hollow diamond charm, tiny top loop, pale rose highlights and magenta edges, pixel art, transparent background, no text.

仅提供物品图标，不包含角色佩戴模型。
