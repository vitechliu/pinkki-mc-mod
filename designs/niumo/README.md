# 牛魔模型

[打开可旋转的 3D 预览](./review.html)。可切换正面、侧面、背面和斜前方，拖动旋转、滚轮缩放。生物可切换动作及拖动时间轴。Blockbench 打开生物工程需要 GeckoLib Models & Animations 插件。

| 工程 | 造型与动作 |
| --- | --- |
| [牛人](./bullman.bbmodel) | 深棕毛色、浅棕牛鼻、短角与黑蹄。待机 2 秒循环，行走 0.8 秒循环，近战右臂挥击 0.55 秒。 |
| [又菜又爱玩](./lao_cai.bbmodel) | 蓝色矮身、宽耳和露齿表情，左手持单枝红玫瑰，右手挥击。待机 2 秒循环，行走 0.55 秒循环，近战 0.55 秒。 |
| [牛魔台](./niumo_table.bbmodel) | 木石台面、金色边带和正面牛头浮雕。放置时正面朝向玩家。 |

模型以 16 单位为一格，脚底为 Y=0，正面朝负 Z。生物挥击由服务端实际命中触发，动画不驱动伤害或位移。玫瑰几何随左臂移动，游戏掉落使用虞美人。

安装 Pillow 后，从仓库根目录运行 `python3 designs/niumo/generate.py` 重新生成工程、游戏资源、Wiki 图标和预览，再运行 `python3 designs/niumo/validate.py` 核对三端资产。Minecraft 客户端渲染另行验收。
