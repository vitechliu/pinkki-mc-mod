## 可复现验证

先准备21.1.264官方安装器的独立服务端到`.local/package-test/1.21.1`，使用已确认的`versions/1.21.1/run/server/eula.txt`。测试脚本只创建`.local/porting-1.21.1/runtime/`下的新世界，绑定`127.0.0.1:25589`、`--nogui`，结束发送stop并核对进程退出；不接触HMCL或已有玩家世界。

```bash
python3 scripts/tests/port_1_21_1_probe/download-dependencies.py
./scripts/mod.sh 1.21.1 build portProbeJar -PportProbe --console=plain
python3 scripts/verify-artifact.py 1.21.1
python3 scripts/smoke-server.py 1.21.1
python3 scripts/check-port-1.21.1.py --geckolib .local/porting-1.21.1/downloads/geckolib-neoforge-1.21.1-4.9.3.jar
python3 scripts/check-jei-linkage.py --minecraft 1.21.1 --api .local/porting-1.21.1/downloads/jei-1.21.1-neoforge-19.70.0.462.jar
```

`--extra-mod <JAR>`可重复指定Curios、Silent Gear/Silent Lib或Iron’s Spells/Curios/Player Animator/Iron’s Lib；各文件URL、版本和SHA512保存在探针`dependencies.json`。每组`result.json`记录输入JAR SHA256、就绪、探针、正常停服、退出码与全部ERROR。

Silent Gear 4.2.1.1自带的10条Woodcutter/Bonsai兼容配方使用旧`conditions`键，缺失对应可选模组时报解析ERROR。已用**没有PinkkiCore**的相同宿主JAR建立独立对照，服务端仍正常就绪及停服。本次不修改第三方JAR；用`--host-baseline`生成对照，再以`--known-host-errors <该对照result.json>`核对相同宿主哈希及相同错误文本，其余ERROR仍失败。不能将此矩阵描述为全日志零ERROR，亦不表示这两种宿主的可选联动可用。

日志汇总位于`.local/porting-1.21.1/`；最终场景与证据目录见下方收尾记录。Wiki已同步适用版本、依赖与玩家更新记录，并通过`npm ci`、`npm run wiki:build`；未更新线上Pages。共享Java及主版本源码未变，本次不运行其他Minecraft目标。
