# 2026-11-24 · 饼蛙追猫

- 变更 ID `2026-11-24-bingwa-cat-hunt`。开始时 HEAD 为 `8202759`。
- 1.20.1 的饼蛙会主动索敌约 16 格内能看见的最近一只猫，野猫、驯服和坐下的猫均可成为目标。目标丢失后会继续搜寻其他猫。保留瓜巴影融和受击反击的较高优先级。
- 沿用两栖寻路和舌击，追猫时将近战寻路倍率从 1.15 提到 6.5，加快陆地转向，并沿着路径追到猫当前所在格。换成其他目标后使用通常的近战速度。舌击继续在前摇结束时判断距离和视线。
- 实现在 1.20.1 的 [BingwaEntity](../../versions/1.20.1/src/main/java/io/github/vitech/pinkkicore/forge/entity/BingwaEntity.java)。离线手册由[饼蛙 Wiki 条目](../../wiki/bosses.md#bingwa)生成，追猫段落限定为 1.20.1。

## 验收场景

1. 在开阔平地上生成饼蛙、野猫和已驯服且坐下的猫。观察饼蛙无需挑衅即可逐只追击并用舌头命中。
2. 让野猫从饼蛙前方全速直线冲刺。比较两者的每刻位移，确认饼蛙能缩短距离，并检查整个追击过程中能否命中。猫躲到实墙后时，舌击仍需检查视线。
3. 切换为瓜巴影融或受击反击目标，检查近战恢复原速。附近只有玩家和其他普通动物时维持中立。
