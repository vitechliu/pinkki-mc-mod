输入是用户提供的离线服务器目录；服务器为 Paper 1.20.6（git-Paper-30），三个世界的 `level.dat` 均声明 DataVersion 3839。原始目录只读，不启动服务器或客户端。

扫描没有报告解析错误。Residence 有 78 个顶级领地，连同子区域、Essentials 家/传送点与 PlayerWarp 的 33 个玩家传送点，共提取 142 个位置线索。CoreProtect 方块记录为空，不能用于完整追踪玩家放置。另盘点到 25 个插件 JAR、40 份玩家数据与 57 份游戏内地图；启用数据包为 vanilla、Bukkit 与 Paper。详细维度范围和资源统计保存在本地 `map-resources.json`。

首轮共输出 7,335 份候选结构（含重叠的总览、领地切片与 89 个位置窗口），其中 153 份有命名位置线索。按当前启发式分类，227 份进入主要候选/待确认范围；其余 1,805 份疑似天然结构、5,303 份地形或零散痕迹仍保留供复核，不能把这些数量当作独立玩家建筑数。

148 份命名局部恢复了 24,465 个邻近原木等细节方块；136 份含恢复的方块实体 NBT。窗口边界和去土规则仍需人工审阅，告示牌、容器物品及插件数据未经目标版本运行验证。

5 个命名位置缺少足够核心信号，待结合反馈补查：主世界 `fenhongshan`、`squ-packed_ice`、`xuediyangzhi`、`蘑菇岛`，末地 `modi`。未达到核心候选阈值的 4,447 处小信号另存审计文件，没有静默当作“无建筑”。

所有大型数据与含服务器内容的产物都位于 `.local/server1011-review/`，受 Git 忽略。工具、方法及恢复页面的命令见 [工具说明](../../tools/world-review/README.md)。

## 实际验证

- 7,335 份结构独立二进制回读成功；共核对 10,055,860 个方块条目（包含重叠），JSON 与 NBT 的每个方块、状态、尺寸、坐标范围一致。
- 所有导出调色板不含排除的泥土/草方块/沙砾等土壤地形；结构 SHA256 均匹配。
- 22,005 个首/中/末样本与原区块的方块状态相符；全部 1,218 个源区域 SHA256 与扫描时一致。
- 实际打开本地页面，确认贴图 3D 渲染、住宅搜索、俯视切换、逐层剖面、坐标总览与审阅状态刷新后恢复。
- 导出使用来源 DataVersion 3839；方块名称均能在本地 1.20.1 的方块资源中找到，但这不证明方块实体/物品 NBT 能降级运行。

未启动 Minecraft 客户端/服务端，未进行游戏内放置验收；未接入 mod、构建或部署发行包。需要用户在审阅页选取并导出清单后，按选中项进行精确边界修整、材料/实体恢复、容器与插件数据清理及 1.20.1 适配。此阶段不涉及玩家已可用玩法，游戏内手册、Wiki、功能适配检查点均不适用。
