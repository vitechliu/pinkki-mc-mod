# 项目与版本

::: info 当前状态
1.20.1 开发版本已实现基础材料瓜巴及其无序合成，尚未发布。结构、多方块和 Boss 等分类仍为占位；游戏内手册尚未实现。
:::

## 主要开发版本

当前日常开发以 **Minecraft Java 1.20.1 / Forge** 为主。1.21.1 / NeoForge 与 1.19.1 / Forge 为次要适配目标，不保证与主版本玩法同步。

每个正式条目将标明适用的 Minecraft 版本与 mod 版本。请勿混用不同版本或加载器的文件。
