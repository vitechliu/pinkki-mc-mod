# 项目与版本

适用 Minecraft Java **1.20.1、1.19.1 / Forge**。安装对应版本的 PinkkiCore 后，可使用[瓜巴手册](./handbook.md)在游戏内离线阅读。

## 阅读目录

- [瓜巴手册](./handbook.md)：获取、阅读与搜索。
- [道具与方块](./items.md)：用途、获取方式与属性。
- [合成与加工](./recipes.md)：材料、加工条件与产物。
- [瓜巴药水](./guaba-potions.md)：每秒波动的移速与护甲，以及酿造方法。
- [瓜巴工作台](./guaba-workbench.md)：转换加工、红石和自动化设置。
- [模组兼容](./compatibility.md)：瓜巴在寂静装备、匠魂与 Tetra 中的用途。
- [世界结构](./structures.md)：寻找条件、结构特点与奖励。
- [多方块](./multiblocks.md)：逐层搭建、激活条件与操作。
- [生物与 Boss](./bosses.md)：召唤、技能、战斗阶段与掉落。
- [更新记录](./changelog.md)：查阅玩法变化。

## 下载与反馈

通过 [GitHub Releases](https://github.com/vitechliu/pinkki-mc-mod/releases) 查看可用发行包。安装说明参见 [仓库 README](https://github.com/vitechliu/pinkki-mc-mod#readme)。

遇到问题可在 [GitHub Issues](https://github.com/vitechliu/pinkki-mc-mod/issues) 反馈，附上 Minecraft、加载器和 mod 版本。
