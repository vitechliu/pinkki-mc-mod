# 生物与 Boss

## 饼蛙 {#bingwa}

适用版本：**Minecraft Java 1.20.1 / Forge · PinkkiCore 0.1.0 开发中，尚未发布**。实体与行为已接入；无头测试结果见开发记录，客户端造型、动作与手持显示仍待人工验收。其他 Minecraft 目标尚未适配。

饼蛙是奶油色、扁胖的两栖中立生物，头顶的小蛙与橘子属于装饰，不是独立乘客。

| 属性 | 当前规则 |
| --- | --- |
| 生命值 | 20（10 颗心） |
| 基础攻击伤害 | 3（1.5 颗心，最终伤害受护甲等影响） |
| 行为 | 陆地缓行、间歇跳跃，水中游动，可在水下呼吸；闲置时鸣叫 |
| 敌对规则 | 平时不主动攻击；受生物或玩家伤害后追击伤害来源，以吐舌反击，不召集附近饼蛙 |
| 获取 | 仅指令或饼蛙刷怪蛋；不自然生成，无繁殖/捕食/专属掉落机制 |

### 召唤与刷怪蛋

```mcfunction
/summon pinkkicore:bingwa ~ ~ ~
/give @s pinkkicore:bingwa_spawn_egg
```

刷怪蛋位于创造模式的**刷怪蛋**分类，采用奶油色底与橘色斑点。对方块顶面使用即可召唤；也沿用原版刷怪蛋的通用交互。没有合成配方或生存模式常规获取方式。

吐舌攻击有短暂前摇，服务端在命中时检查距离及视线。和平/创造模式下的目标规则沿用原版 AI；不把它当作主动攻击玩家的怪物。
