# 生物与 Boss

## 饼蛙 {#bingwa}

饼蛙是奶油色、扁胖的两栖中立生物。平时不会主动攻击，受伤后会追击攻击者并用舌头反击。

| 属性 | 说明 |
| --- | --- |
| 生命值 | 20（10 颗心） |
| 基础攻击伤害 | 3（1.5 颗心） |
| 活动方式 | 陆地行走、跳跃，水中游泳，可在水下呼吸。 |
| 出现方式 | 使用[饼蛙刷怪蛋](./items.md#bingwa-spawn-egg)或召唤指令，也会在主世界野外低概率出现。 |

召唤指令：

```mcfunction
/summon pinkkicore:bingwa ~ ~ ~
```

## 粉红妹 {#pinkki}

粉红妹是中立的人形 NPC，平时四处游荡、看向附近玩家，受到攻击后会近战反击。生命值为 20（10 颗心）。

可使用[粉红妹刷怪蛋](./items.md#pinkki-spawn-egg)，或输入：

```mcfunction
/summon pinkkicore:pinkki ~ ~ ~
```

将武器、盾牌或护甲丢在附近，她会走近拾取并按原版生物规则换上更合适的装备。支持主手、副手及四个护甲槽，拾取的装备会随她保存，死亡时掉落（消失诅咒仍生效）。关闭 `mobGriefing` 时不会自动拾取。

弓、弩、三叉戟和盾牌可以装备，目前反击使用近战，不会射击、投掷或主动举盾。

## 头顶名称

粉红妹、瓜巴影融和饼蛙出生后默认显示各自的名字，无需使用命名牌。仍可用命名牌重新命名，改名会随存档保存。

## 瓜巴影融 {#guaba-yingrong}

瓜巴影融是中立的人形 NPC，生命值为 20（10 颗心）。平时四处游荡、观察附近玩家，受击后会近战反击。

使用[瓜巴影融刷怪蛋](./items.md#guaba-yingrong-spawn-egg)，或输入：

```mcfunction
/summon pinkkicore:guaba_yingrong ~ ~ ~
```

将武器、盾牌和护甲丢在附近，他会走近拾取并按原版生物规则换上更合适的装备。支持主手、副手及四个护甲槽，装备随存档保存；拾取的装备在死亡时掉落，消失诅咒仍生效。关闭 `mobGriefing` 时不会自动拾取。

弓弩、三叉戟和盾牌可以装备，目前不会射击、投掷或主动举盾。

## 野外遇见与掉落 {#wildlife}

粉红妹、瓜巴影融和饼蛙会低概率、单只出现在主世界明亮、露天的草地上，例如平原、森林、针叶林和沼泽中的合适地面；不会在下界或末地自然生成。附近 64 格内已有三只这些生物时，会停止继续自然刷新。原有刷怪蛋和召唤指令仍可使用。

三者每次死亡随机掉落下列一种材料：

| 材料 | 数量 | 概率 |
| --- | --- | --- |
| 瓜巴 | 1–3 | 70% |
| 雷霆瓜巴 | 1–2 | 20% |
| 粉红锭 | 1–2 | 10% |

这些材料掉落不要求玩家击杀，不受抢夺加成影响；关闭 `doMobLoot` 时不掉落。NPC 原本穿戴、拾取的装备仍按原有规则掉落。
